# UniMorph corpus data

This directory incorporates, filters and reindexes data from [UniMorph Latin](https://github.com/unimorph/lat) and [UniMorph Ancient Greek](https://github.com/unimorph/grc). They are distributed under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Derivative corpus indexes under this directory carry that license and require attribution and share-alike. Upstream original source SHA, source checksums and counts are in manifest.json. Code outside this directory is separate.
